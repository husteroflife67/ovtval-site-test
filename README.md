# ОТВАЛ — статический сайт производителя

Шесть страниц, каталог и настоящий параметрический 3D-конструктор на Three.js. Интерфейс на русском языке. Сборка, Node.js, API, база данных и сервер приложения не нужны. Three.js 0.169.0 и OrbitControls хранятся локально; внешних CDN, шрифтов, аналитики и сервисов изображений нет.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

Откройте `index.html` через этот HTTP-сервер. Открытие HTML двойным кликом через `file://` не поддерживается браузерными ES-модулями. Для запуска подходит любой статический HTTP-сервер. Python нужен только для удобного локального просмотра, GitHub Pages его не использует.

## Страницы

- `index.html` — главная, интерактивная модель, преимущества и подбор продукции.
- `catalog.html` — шесть моделей, фильтр техники и сортировка.
- `constructor.html` — семь групп настроек, калькулятор, проекты и заявка.
- `production.html` — описание производства и этапов работы.
- `delivery.html` — доставка, оплата и ответы на вопросы.
- `contacts.html` — контакты и форма обратной связи.

Конструктор поддерживает шесть типов отвала, габариты, три материала, пять креплений, три механизма поворота, параметры гидравлики, семь визуальных опций и цвета. Ракурсы спереди, сбоку, сверху, сзади и в перспективе, вращение, масштаб и полный экран. Разрешение рендера ограничено для мобильных устройств; невидимые сцены не отрисовываются. Если WebGL недоступен, расчёт и формы продолжают работать.

## Что изменить перед коммерческой публикацией

В `assets/config.js` находятся:

- `COMPANY`: название, адрес, телефон, email и режим работы. После указания действующего email установите `contactsConfigured: true`.
- `PRICING`: базовая цена, плотность стали, стоимость за кг, коэффициенты типов и материалов, цены креплений, механизма, покраски и опций.
- `DEFAULT`: начальная конфигурация.

Контакты сейчас — явные заглушки. Формы не отправляют данные, пока `contactsConfigured` выключен. После включения кнопка открывает `mailto:` с заполненным письмом. **Это не подтверждение отправки**: пользователь отправляет письмо самостоятельно в настроенном почтовом клиенте. Если клиент отсутствует или письмо слишком длинное для него, скачайте TXT-комплектацию и приложите к письму вручную. Форма на сайте не получает доставку или ответ сервера.

Все расценки, масса и геометрия демонстрационные. 3D-модель не является рабочим чертежом или инженерным расчётом. Подтвердите реальные производственные возможности, гарантии, условия оплаты, доставки, юридические сведения и обработку персональных данных. Тексты производства — редактируемый шаблон без вымышленных сертификатов и статистики.

## Проекты и выгрузка

Черновик автоматически хранится в `otval-draft`, до 30 именованных проектов — в `otval-projects` в LocalStorage. Контактные данные туда не записываются. Проекты доступны только в этом браузере; очистка данных сайта удаляет их. В приватном режиме или при запрете LocalStorage сохранение может быть недоступно — скачайте комплектацию в UTF-8 TXT. Файл содержит все параметры, разбивку стоимости, массу и предупреждение о предварительном расчёте.

## GitHub Pages

Все ссылки относительные: сайт работает и в корне, и по адресу проекта `/ovtval-site-test/`.

1. Добавьте файлы в репозиторий и отправьте коммит в `main`.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` публикует только HTML, `assets/` и `.nojekyll`, без установки зависимостей и сборки.
4. Проверьте завершение workflow и сайт по адресу, который покажет GitHub.

Альтернатива: публикация из ветки `main`, каталог `/ (root)`, через настройки Pages. Во время разработки коммиты, push и публикация автоматически не выполняются.

## Проверки

Для сайта никаких тестовых зависимостей устанавливать не нужно. Дополнительные тесты предназначены только для разработки:

```sh
node tests/pricing.mjs
```

Проверяются расчёт всех вариантов, сумма компонентов, влияние семи опций, ограничения и покраска.

Браузерные проверки используют Playwright. Установите его в отдельное окружение для инструментов, запустите HTTP-сервер выше, затем:

```sh
NODE_PATH=/path/to/tools/node_modules node tests/browser.cjs
```

По умолчанию Playwright использует свой Chromium. Для системного браузера можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium`. `BASE_URL` позволяет проверить сайт по другому адресу (с завершающим `/`). Проверяются 14 сценариев: 3D, изменение цены, гидравлика и оснащение, ограничения размеров, восстановление черновика, сохранение проекта, TXT, итоговая комплектация, камера, полный экран, каталог, переход с готовыми параметрами и мобильные страницы. Скриншоты записываются в `/tmp/otval-*.png`.

Дополнительная проверка почтового сценария (включает контакты только в перехваченных браузерных ответах), работы без внешней сети и экрана 320 px:

```sh
NODE_PATH=/path/to/tools/node_modules node tests/mail-flow.cjs
```

Встроенные библиотеки: `assets/vendor/THREE-LICENSE.txt` (MIT). Изображения каталога получены из параметрической модели проекта.
